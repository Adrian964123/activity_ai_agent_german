# activity_ai_agent_german
Using OpenAI and Google Geocoding API

1. Put every file (Template folder and app.py) in the same folder for it to work.

2. For the API Keys create a .env file using the Text editor or Notepad. Name should only be .env.
Example:
OPENAI_API_KEY=YOUR_KEY_HERE
GEOCODING_API_KEY=YOUR_KEY_HERE

Modules used: Flask and OpenAI latest version.
